התחלה מהירה

שלוש דקות מהמפתח לנתונים.

  1. קבלו מפתח מנהל המערכת מייצר אותו בדשבורד ושולח לכם. המפתח נראה כך: reap_…
  2. שלחו בקשה כל קריאה היא GET רגיל עם כותרת Authorization.
  3. קבלו JSON סכומים מוכנים לשימוש — בלי צורך לחשב ממוצעים או פילוחים.
הבקשה הראשונה
curl -H "Authorization: Bearer $REAP_API_KEY" \
  "https://reap-dashboard.vercel.app/api/v1/summary?month=2026-08"

אימות

כל נקודת קצה דורשת מפתח, למעט GET /api/v1 שמחזירה רק את רשימת הנקודות.

שיטהאיך שולחיםמתי להשתמש
BearerAuthorization: Bearer reap_…ברירת המחדל
כותרת ייעודיתx-api-key: reap_…כשקל יותר לכלי שלכם
שורת כתובת?api_key=reap_…מוצא אחרון — נשמר בלוגים של שרתים
המפתח שווה ערך לגישה לנתונים

השתמשו בו מצד השרת בלבד, ממשתנה סביבה. מפתח שנחשף — מנהל המערכת מוחק אותו בדשבורד ומנפיק חדש, והישן מפסיק לעבוד מיידית.

לכל מפתח מוגדרות חברות מותרות וכרטיסים חסומים. בקשה לנתונים שמחוץ להרשאה מחזירה תוצאה ריקה ולא שגיאה — כדי לראות מה המפתח שלכם מורשה לראות, קראו ל־/me.

שגיאות

כל שגיאה חוזרת באותו מבנה: { "error": { "code", "message" } }.

קודHTTPמה קרה ומה לעשות
missing_api_key401לא נשלח מפתח — הוסיפו כותרת Authorization
invalid_api_key401המפתח לא מוכר — ודאו שהועתק במלואו
key_disabled403המפתח הושבת בדשבורד — פנו למנהל המערכת
key_expired403עבר תאריך התפוגה — צריך מפתח חדש
bad_request400פרמטר שגוי — ההודעה מציינת בדיוק איזה ומה הפורמט הנכון
internal_error500תקלה בצד השרת — נסו שוב, ואם חוזר דווחו

דוגמאות קוד

המפתח תמיד ממשתנה סביבה, תמיד מצד השרת.

Node.js
// הוצאות הרבעון לפי חברה
const url = new URL("https://reap-dashboard.vercel.app/api/v1/companies");
url.searchParams.set("from", "2026-07-01");
url.searchParams.set("to", "2026-09-30");

const res = await fetch(url, {
  headers: { Authorization: `Bearer ${process.env.REAP_API_KEY}` },
});
if (!res.ok) throw new Error((await res.json()).error.message);

const { totals, groups } = await res.json();
console.log(totals.total, groups.map((g) => [g.key, g.total]));
Python
# עשרת הספקים הגדולים מתחילת השנה
import os, requests

r = requests.get(
    "https://reap-dashboard.vercel.app/api/v1/suppliers",
    headers={"Authorization": f"Bearer {os.environ['REAP_API_KEY']}"},
    params={"from": "2026-01-01", "to": "2026-08-31"},
    timeout=30,
)
r.raise_for_status()

for g in r.json()["groups"][:10]:
    print(g["key"], g["total"], g["monthly_avg"])

אבטחה ותפעול

  • קריאה בלבד. אין דרך לשנות, להוסיף או למחוק נתונים דרך ה־API.
  • הרשאות לכל מפתח. חברות מותרות, כרטיסים חסומים ותאריך תפוגה — נקבעים בדשבורד ונאכפים בשרת.
  • CORS פתוח כברירת מחדל. להגבלה לדומיינים מוכרים: משתנה הסביבה API_ALLOWED_ORIGINS.
  • אין הגבלת קצב. הימנעו מפולינג תכוף; לקריאות חוזרות סננו לפי חודש או טווח תאריכים, ושמרו תוצאות במטמון אצלכם.
  • סכומים מעוגלים לשתי ספרות אחרי הנקודה, במטבע USD.

התיעוד המלא נמצא גם במאגר הקוד של הדשבורד תחת docs/API.md. לשאלות ולהנפקת מפתחות — מנהל המערכת של Reap.
